kaspflow — 실시간 암호화폐 시세 파이프라인

Binance WebSocket에서 들어온 체결 데이터가 Kafka와 Spark를 거쳐 1분봉 OHLC로 PostgreSQL에 쌓이고, FastAPI와 React 대시보드로 서빙되는 전체 구성.

데이터 흐름

  • Binance WS → producer → Kafka 토픽 crypto-trades
  • Spark Structured Streaming이 1분봉 OHLC로 집계해 호스트 PostgreSQL crypto.ohlc_1m에 적재
  • FastAPI가 조회하고 React 대시보드(lightweight-charts)가 차트로 표시

접근 경로 · 배포

  • Caddy가 bit-kaspflow.duckdns.org TLS 종단, /api/*는 8010, 나머지는 8501로 분기
  • 자동 배포: kaspflow-autodeploy.timer가 약 2분마다 GitHub main 폴링 → compose pull/up → /health 실패 시 롤백

주의

  • 8501 대시보드가 평문(HTTP)으로도 외부 노출
  • Kafka UI(8090)는 무인증 (외부 차단 상태)
  • PostgreSQL 백업 없음
