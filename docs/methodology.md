# 검증 방법론

kaspflow 2세대는 "이 종목을 지금 사도 되나, 팔아야 하나, 기다려야 하나"에 답한다. 원칙은 세 가지다.

1. **계산은 코드가, 설명은 LLM 이.** 판단은 재현 가능한 계량 엔진이 정한다. NIM(LLM)은 뉴스 분류,
   투자 대가 관점의 의견, 판단 해설을 쓰지만 판단 자체를 바꾸지 못한다 (FinRobot 의 "models reason, software computes").
2. **검증을 통과한 신호만 쓴다.** 전략 백테스트는 표본 밖 성과, 순열 검정, 다중 검정 보정을 통과해야 판단에 들어간다.
3. **근거가 약하면 관망.** 모듈 점수에 신뢰도를 곱해 합치므로 근거가 엇갈리거나 부족하면 점수가 0 쪽으로 줄어든다.

## 2. 전략 백테스트와 검증 (`strategies.py`, `backtest.py`, `validation.py`)

**전략 11개, 변형 30개.** midas-touch 에서 이식한 6개(이동평균 교차, MACD, RSI 돌파, 볼린저 복귀, OBV, 복합 다수결)와
널리 알려진 5개(돈치안 돌파/터틀, 시계열 모멘텀/Moskowitz 2012, 장기 추세 필터/Faber 2007, RSI(2)/Connors 2008,
변동성 돌파/Larry Williams).

**체결 모델.** 판단은 t일 종가, 체결은 t+1일 시가. 시가 갭은 기존 포지션이, 장중은 새 포지션이 받는다.
편도 비용 0.05%, 현금은 ^IRX 금리. 조정가라서 단순 보유도 배당 재투자 총수익이다. 모든 신호는 t 시점까지의
데이터만 쓴다 (`test_no_lookahead` 가 확인).

**검증 단계**

1. 워크포워드: 직전 3년(IS)에서 샤프가 가장 높은 변형을 골라 다음 1년(OOS)에 쓴다. 1년씩 밀며 반복하고
   OOS 구간만 이어 붙인다. 화면의 성과 숫자는 전부 이 OOS 성과다.
2. 몬테카를로 순열 검정: OOS 보유 배열을 시간축으로 1,000번 원형 이동한다. 보유 기간 구조와 노출 비율은 그대로라
   "타이밍 실력"만 검정한다. 상승장에서 아무 때나 들고 있어도 수익이 나는 효과를 걸러 낸다.
   변동성 돌파(하루짜리)는 "아무 날 시가에 사서 다음 날 시가에 파는 것"의 평균과 비교한다.
3. DSR (Deflated Sharpe Ratio, Bailey & López de Prado 2014): 이번에 시험한 30개 변형의 샤프 분산으로
   "최고 샤프의 기대치"를 계산하고, 그보다 진짜로 높을 확률을 낸다 (왜도·첨도 반영).
4. 거래 재표본: OOS 거래를 복원 추출로 1,000번 섞어 최종 수익·최대 낙폭의 분위수를 낸다.

**등급** (판단 가중치): A 1.0 (p≤0.05, OOS 샤프≥0.5, 거래≥15, DSR≥0.8) · B 0.6 (p≤0.10, 샤프≥0.3, 거래≥8, DSR≥0.5)
· C 0.25 (p≤0.25, 샤프>0, 거래≥5) · F 0 (판단에 안 씀).

**지금 신호.** 가장 최근 3년에서 샤프가 가장 높은 변형의 마지막 결정. 추세 전략은 "현금 = 약세", 역추세 전략은
"현금 = 중립"으로 읽는다. 검증 등급으로 가중 평균한 값이 '검증된 전략 신호' 모듈 점수다.

실측 (2026-11-16, 10년 일봉): AAPL·NVDA·KO 에서 대부분의 타이밍 전략이 순열 검정을 통과하지 못했다 (p>0.1).
학계의 일반적 결론(단일 종목 기술적 타이밍의 우위는 약하다)과 맞는다. 통과 전략이 없으면 이 모듈은 판단에서 빠진다.

## 3. 시뮬레이션 (`simulation.py`)

- 몬테카를로: 최근 3년 일간 로그수익률을 정상 블록 부트스트랩(Politis & Romano 1994, 평균 블록 10일)으로
  2,000개 1년 경로를 만든다. 드리프트는 과거 평균 대신 CAPM(무위험 금리 + 베타 x 4.5%)으로 바꾼다.
  과거에 많이 오른 종목을 낙관적으로 시뮬레이션하는 편향을 막기 위해서다. 그래서 방향 점수는 내지 않고
  가격 범위, 손절·목표 도달 확률, CVaR 같은 위험 정보만 준다.
- 매매 계획: 손절·목표 = ATR(14) x (단기 2/4, 중기 3/6, 장기 5/10). 경로 위에서 어느 쪽에 먼저 닿는지 센다.
  비중 = 계좌의 1% 손실 한도 / 손절 거리 (최대 25%). 검증 등급 A·B 전략이 있으면 하프 켈리도 보여 준다.
- 과거 유사 국면: 200일선 위/아래, 3개월 모멘텀 부호, RSI 구간이 같았던 날들의 N일 뒤 수익률을 전체 평균과
  비교한다. 겹치는 구간 때문에 유효 표본을 n / (2H/3) 로 줄여 t 값을 낸다.

## 4. 재무 · 밸류에이션 · 컨센서스 (`fundamentals.py`)

- 품질: 수익성(ROE, ROIC, 영업이익률), 성장성(매출·EPS 3년 CAGR), 건전성(D/E, 이자보상배율, 유동비율,
  알트만 Z), 이익의 질(FCF 마진, 현금흐름/순이익, 피오트로스키 F 9항목).
- DCF: FCFF(영업현금 + 세후이자 - 설비투자 - 주식보상) 최근 2년 평균, 1~5년 성장률 = 애널리스트 성장률·매출 CAGR·
  EPS CAGR 의 중앙값(-5%~30%), 6~10년 영구성장률 2.5% 로 선형 수렴, 연중 할인. WACC = CAPM 자기자본비용
  (10년물 + Blume 조정 베타 x 4.5%) 과 세후 부채비용의 시가 가중 (6~15%). WACC ±1%p x 영구성장률 ±0.5%p
  민감도, 터미널 가치 비중 75% 초과 경고. 절차는 anthropics/financial-services 의 dcf-model 스킬(Apache-2.0)을 따랐다.
- 역DCF: 현재가를 맞추는 1~5년 성장률을 이분법으로 푼다. "현실적 성장률"보다 높으면 고평가 쪽.
- 그 밖의 모델: PEG=1 적정 PER(성장률 x 100, 8~30배), 그레이엄 공식(성장률 10% 제한), 그레이엄 넘버, EPV.
  중심 적정가 = DCF 50% · PEG 30% · 그레이엄 공식 20%. EPV·그레이엄 넘버는 보수적 하한으로만 표시한다.
- 컨센서스: 투자의견 평균, 목표가 괴리(평균적인 +8% 낙관 편향을 뺌), 최근 30일 EPS 추정 상향-하향, 90일 등급 변경.

## 5. 뉴스 감성과 투자 대가 (`news.py`, `personas.py`)

- 뉴스: 기사 제목을 20개씩 NIM 에 보내 관련도·감성(-1~+1)·영향도·사건 유형·한국어 제목을 받는다.
  가중치 = 관련도 x 영향도 x exp(-경과일/7), 주가 등락 기사는 0.3배. 기사별 라벨은 7일 캐시.
- 투자 대가 6인(버핏, 그레이엄, 린치, 멍거, 캐시 우드, 드러켄밀러): 각자 5~7개 체크리스트를 코드로 계산하고,
  NIM 이 그 관점으로 의견을 쓴다. 점수 = 체크리스트 50% + LLM 의견 50%. 기준값은 virattt/ai-hedge-fund v1(MIT)의
  결정적 점수 로직과 각자의 저서·서한을 참고했다. 실제 인물의 견해가 아니다.

## 6. 판단 엔진 (`verdict.py`)

S = Σ(가중치 x 신뢰도 x 점수) / Σ 가중치. S ≥ +0.15 매수, ≤ -0.15 매도, 그 사이 관망. |S| ≥ 0.35 면 '강한'.

| 모듈 | 단기(1개월) | 중기(3개월) | 장기(1년) |
|---|---|---|---|
| 기술적 지표 | 22% | 12% | 4% |
| 검증된 전략 신호 | 22% | 15% | 5% |
| 과거 유사 국면 | 8% | 6% | 2% |
| 뉴스 감성 | 16% | 10% | 4% |
| 애널리스트 컨센서스 | 6% | 12% | 10% |
| 밸류에이션 | 4% | 15% | 28% |
| 재무 품질 | 2% | 12% | 25% |
| 투자 대가 패널 | 5% | 10% | 18% |
| 시장 국면 | 15% | 8% | 4% |

신뢰도 = 근거 커버리지 x (0.5 + 0.5 x 근거 일치도). 실적 발표 10일 이내면 x0.85, 연 변동성 60% 초과면 x0.9.
보유 정보를 넣으면 같은 판단도 "보유 유지 / 비중 축소" 처럼 보유자 기준으로 풀어 준다.

## 7. 사후 검증 (판단 기록)

모든 실행은 `stock.analysis_run` 에 저장된다. 판단 기간(30/91/365일)이 지나면 midas-touch 판단 원장과 같은 기준으로
적중을 매긴다: 매수는 +2% 초과, 매도는 -2% 미만, 관망은 ±5% 이내. 기록 화면의 적중률이 이 검증기 자체의 성적표다.

관심 종목(최대 10개)은 평일 16:40(뉴욕, 장 마감 뒤) 하루 한 번 자동으로 판단해 기록이 쌓이게 한다 (`app._autorun_loop`, `AUTORUN=0` 으로 끔).

### 판단 엔진의 과거 성적 (부분 검증, `engine_backtest.py`)

대형주 31개의 10년 일봉으로 매달 한 번, 그 시점까지의 데이터만 써서 판단을 다시 내고 1·3·12개월 뒤 결과와 맞춘다.
과거 시점 값이 있는 기술적 지표, 과거 유사 국면, 시장 국면만 쓴다 (가중치로 단기 45%, 중기 26%, 장기 10%).
적중률은 '같은 기간에 늘 그 판단을 했을 때' 의 기준선과 나란히 본다 (생존 편향 때문에 생 적중률은 부풀려진다).

2026-11-17 계산 결과: 세 기간 모두 판단별 적중률이 기준선과 거의 같았다 (예: 단기 매수 45.7%, 기준선 46.9%).
매도 판단 뒤 주가가 오히려 평균보다 더 올랐고, 신뢰도가 높은 판단이 더 잘 맞지도 않았다. 이 세 모듈의 가중치를 다시 볼 근거다.
결과는 `dashboard/src/engine-backtest.json` 에 두고 '검증 방법' 페이지가 그린다. 다시 계산: `.venv/bin/python engine_backtest.py --out ../dashboard/src/engine-backtest.json` (약 40초).

## 8. 한계

- 단일 종목 10년 일봉은 표본이 작다. 통계 검정을 통과해도 미래에 같은 우위가 유지된다는 보장은 없다.
- yfinance 재무제표는 최근 4~5년뿐이라 장기 평균(10년 ROE 등)을 보지 못한다.
- 뉴스는 제목 기반이다. 본문·공시(8-K)·실적 발표 내용은 보지 않는다.
- 세금, 환율(원/달러), 대량 주문의 시장 충격은 반영하지 않는다.
- 투자 권유가 아니다.
